# Dementia Risk Prediction Using UK Biobank Data

A comprehensive analysis pipeline for predicting dementia risk stratified by type (Alzheimer's Disease, Vascular Dementia, and Vascular-Related Dementia) using UK Biobank data and advanced statistical modeling.

## Project Overview

This repository contains the complete analysis codebase developed for a Master's thesis on dementia risk prediction. The project combines genetic factors (polygenic risk scores, APOE genotypes), clinical variables, and demographic information to build competing risk models for three types of dementia using competing risk regression techniques.

### Key Features
- **Three Dementia Types**: Separate risk models for Alzheimer's Disease (AD), Vascular Dementia (VD), and Vascular-Related Dementia (VRD)
- **Competing Risk Framework**: Fine-Gray regression models accounting for competing risks (death and other causes)
- **10-Year Risk Prediction**: Absolute and relative risk estimates stratified by key clinical factors
- **Interactive Risk Charts**: Visualizations of risk stratified by age, sex, APOE genotype, and genetic risk scores
- **Model Validation**: Comprehensive diagnostics including proportional hazards assumptions, model comparison, and feature selection

## Data

The analysis uses data from the **UK Biobank**, a large prospective cohort study with over 500,000 participants. The specific data file (`custom_data_1.tsv`) is not included in this repository due to data access restrictions.

### Data Access
UK Biobank data requires an approved application. Access information is available at: https://www.ukbiobank.ac.uk/

### Included Variables
- **Demographics**: Age, sex, education
- **Genetic Factors**: APOE genotype (ε22, ε32, ε33, ε42, ε43, ε44), Polygenic Risk Score (PRS)
- **Clinical Factors**: Systolic/diastolic blood pressure, history of hypertension, IHD, stroke
- **Lifestyle**: Smoking history, alcohol consumption
- **Outcomes**: Dementia diagnosis (AD, VD, VRD), event time, censoring status

## Methods

### Statistical Approach

**Competing Risk Regression**: Fine-Gray regression models accounting for the competing risk of death and other causes of dementia. This is more appropriate than standard Cox regression when multiple mutually exclusive events are possible.

### Model Development

1. **Data Preparation** (`formatting.R`):
   - Train/test split (likely 80/20 or similar)
   - Data cleaning and variable encoding
   - Separate datasets for AD, VD, and VRD

2. **Model Fitting**:
   - **Full Model**: Includes all clinical and genetic variables
   - **Reduced Model**: Selected variables via LASSO feature selection
   - **Spline Models**: Assess non-linear relationships

3. **Model Selection**:
   - ANOVA tests comparing nested models
   - AIC comparison
   - Assessment of proportional hazards assumption (Schoenfeld residuals)

4. **Risk Stratification**:
   - 10-year absolute risk predictions across scenarios
   - Stratified by: age groups, sex, APOE genotype, PRS quintile
   - Relative risk calculations using reference group

### Diagnostics

- **Forest plots**: Hazard ratios with 95% confidence intervals
- **Proportional hazards tests**: Schoenfeld residuals and log-log plots
- **Spline plots**: Non-linear associations between predictors and outcomes

## Key Analyses

### 1. Forest Plots
Visualizations of hazard ratios for all variables in the Cox models, generated by `plot_forest.R`.

### 2. Fine-Gray Regression Models
Competing risk regression models fit using the `riskRegression` package:
- Produces sub-distribution hazard ratios
- Accounts for competing risk of death
- Models fit separately for AD, VD, and VRD

### 3. 10-Year Risk Charts
Interactive heatmaps showing absolute risk of dementia at 10 years:
- Rows: APOE genotype (ε22 to ε44)
- Columns: PRS quintile (1-5, with 3 as reference)
- Color-coded by risk category (0-100%)
- Faceted by age group, sex, and education level

### 4. Feature Selection
LASSO Cox regression to identify minimal set of important features for each dementia type.

### 5. Model Comparison
Comparison between full and reduced models via:
- ANOVA tests
- AIC values
- Cross-validation or similar metrics (may be implemented)

## Usage

### Running the Full Pipeline

```r
# Run main analysis script
source("scripts/main.R")
```

The script executes in order:
1. Load libraries and data
2. Data formatting and train/test split
3. Create analysis table
4. Generate forest plots
5. Fit Cox proportional hazards models
6. Fit Fine-Gray competing risk models
7. Generate 10-year risk predictions and charts
8. Model diagnostics (Schoenfeld residuals, log-log plots)
9. Feature selection via LASSO
10. Generate summary statistics

### Key Outputs

- **Risk Charts** (`Results/`): PDF files with heatmaps of absolute risk stratified by demographics and genetics
- **Model Fits** (`fits/`): RDS files containing fitted FGR models for AD, VD, VRD
- **Diagnostic Plots** (saved via `plot_*` functions): Forest plots, spline curves, residual plots

## Results Interpretation

### Hazard Ratios
- **HR > 1**: Increased risk with each unit increase in variable
- **HR < 1**: Decreased risk
- Adjusted for other variables in the model

### 10-Year Risk
- **Absolute risk**: Probability of developing specific dementia type by 10 years
- Ranges from 0-100%
- Risk stratified by demographics and genetic factors

### Risk Ratios
- **Relative to reference group**: Women, no diabetes, never smoking, e33 APOE, median PRS, age 70-80, normal education
- Values > 1 indicate higher risk than reference
- Useful for understanding disease burden in high-risk groups

## Limitations & Considerations

- UK Biobank cohort demographics may not generalize to all populations
- Dementia ascertainment through linkage records (may underestimate cases)
- Competing risk of death affects risk estimates, especially in older ages
- Polygenic risk scores based on European ancestry GWAS
- Cross-validation or external validation performance not detailed here
